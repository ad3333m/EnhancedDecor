# EnhancedDecor

Wear any avatar decoration, profile effect, nameplate or profile frame from the whole Discord shop, for free.
It only changes what your own phone draws: nobody else sees it.

## Install (Endcord Mobile, Revenge, Kettu, Bunny)

Copy this link, then in Discord open **Settings → Endcord → Plugins → + (install from link)** and paste it:

```
https://raw.githubusercontent.com/ad3333m/EnhancedDecor/main/
```

Open the plugin's settings to pick. Tap an item again, or **None**, to take it off.

The catalog comes from [litruv/discord-collectibles](https://github.com/litruv/discord-collectibles) (a weekly dump of
the shop) plus Discord's live shop, and everything seen is kept, so items that leave the shop stay pickable.
